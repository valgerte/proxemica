# Проксемика

Аудиовизуальный синтезатор на Three.js и Tone.js. Записи хранятся локально в IndexedDB.

## Запуск

Node.js 20 или новее.

```sh
npm ci
npm run dev
```

## Сборка

```sh
npm run build
```

Размещайте содержимое dist на статическом хостинге. Для микрофона нужен HTTPS или localhost.

Версия 0.1: процедурная 3D-геометрия, запись и импорт звука, слои и эффекты. Визуал пока приближённый; экспорт микса не реализован.
